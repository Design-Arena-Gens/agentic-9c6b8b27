# Job Recruitment Platform MVP

A full-stack job recruitment platform inspired by ZipRecruiter, built with React, Node.js/Express, and Firebase.

## 📋 Description

This MVP solves two main problems for employers:
1. **Job Posting**: Post once and distribute to multiple job boards (simulated for MVP)
2. **Applicant Management**: Funnel all applications into one simple dashboard

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 16 or higher)
- [npm](https://www.npmjs.com/)
- Firebase project (optional for demo)

### Backend Setup

1. Navigate to backend directory:
   ```bash
   cd backend
   npm install
   ```

2. Create `.env` file (optional for demo):
   ```
   PORT=8000
   FIREBASE_PROJECT_ID=your-project-id
   FIREBASE_PRIVATE_KEY=your-private-key
   FIREBASE_CLIENT_EMAIL=your-client-email
   ```

3. Start backend:
   ```bash
   npm start
   ```
   Backend runs on `http://localhost:8000`

### Frontend Setup

1. Navigate to frontend directory:
   ```bash
   cd frontend
   npm install
   ```

2. Create `.env` file:
   ```
   VITE_API_URL=http://localhost:8000
   VITE_FIREBASE_API_KEY=your-api-key
   VITE_FIREBASE_AUTH_DOMAIN=your-auth-domain
   VITE_FIREBASE_PROJECT_ID=your-project-id
   VITE_FIREBASE_STORAGE_BUCKET=your-storage-bucket
   VITE_FIREBASE_MESSAGING_SENDER_ID=your-sender-id
   VITE_FIREBASE_APP_ID=your-app-id
   ```

3. Start frontend:
   ```bash
   npm run dev
   ```
   Frontend runs on `http://localhost:5173`
